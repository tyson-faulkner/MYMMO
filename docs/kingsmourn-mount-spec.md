# Kingsmourn — Mounts

Ten mounts, from Tyson's reference sheet (2026-09-11). Each is a model, a ride
animation, and a speed buff — cheap mechanically, and among the most motivating
rewards in the genre.

## Why ten is affordable

**Seven of these share one quadruped rig.** Tiger, saber, two bears, hound,
rhino, devilsaur — one skeleton, one run cycle, seven skins and silhouettes.
Exactly the trick the humanoids use.

**Three are machines**, which need no rig at all: a prop the rider sits on,
with wheels or legs that animate on a simple loop.

So the real bill is one quadruped rig, seven variants, three props.

## The first three

The design doc asked for exactly three — one world, one dungeon, one heroic
raid. Build these first; the rest fill in.

1. **Scrap Chopper** — a machine, so no rig, so cheapest. Everyone's first
   mount, bought from Odda once they can afford it. Sovereigns finally have a
   big-ticket sink.
2. **Veil Saber** — the first quadruped, which means building the shared rig.
   Drops from the First King. Purple, skull-faced, green fire.
3. **Ironhide** — the heroic raid's unique reward. Armoured, red-eyed, the
   biggest thing anyone rides.

## How it works in-game

- A mount is an item in the bag. Using it summons the mount and puts you on it.
- Mounted speed is roughly 1.6x running. Dismount on taking damage or attacking.
- Mounts are account-wide once learned, not consumed — you keep it forever.
  (Implemented per-character for now; see APPLY_THESE.md.)
- No mounts inside dungeons or the raid.

## Style

Match the reference sheet's read: heavy silhouettes, saddle and harness on
every one so they read as *ridden* rather than as enemies, painted texture
detail, saturated colour. The Tinker's machines and the necromancer's bone
things should look like they came from the same workshops as the Tinker's
turret and the Grave-Binders' work.
